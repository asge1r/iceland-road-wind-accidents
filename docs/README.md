# Documentation

This directory contains the small, version-controlled documents needed to
understand and rerun the analysis without access to the local raw-data files.

- `data_sources.md`: source organisations, download locations and raw files.
- `variables.md`: variables retained in the canonical processed datasets.
- `methods.md`: analysis populations, matching rules and main limitations.

`pipeline.md` in the project root is the execution map: it identifies the
script, input and output at each step.
