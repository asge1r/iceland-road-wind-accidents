# University of Iceland thesis template

The official University of Iceland MSc LaTeX template is maintained at
[`gitlab.com/uice/thesistemplate`](https://gitlab.com/uice/thesistemplate).

The thesis uses the template's title-page structure, two-sided KOMA-Script
layout (`a4paper`, `BCOR=10mm`), Latin Modern font, italic captions, front
matter and appendix arrangement. The template's 12-point body and full-line
paragraph gap are intentionally adjusted to 11-point body text and a 0.45-line
paragraph gap, following the supervisor's presentation guidance. No custom
margin package overrides the KOMA-Script layout. `draft_en.tex` is the master
file; it loads `content.tex` for the main text and `appendices.tex` for
supporting analyses. `banner.png` is the unmodified cover asset supplied with
the template.

The template change affects presentation only. It does not change the data,
analysis scripts or statistical results.
